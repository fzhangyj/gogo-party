# 滚滚奇遇 · GOGO PARTY

一个可以直接玩的 Godot 4 原创 3D 跑酷游戏，采用圆滚滚的角色与玩具乐园风格。当前是本地单人计时挑战，六张地图全部开放。

## 启动

- **双击 `开始游戏.bat`**。启动器使用桌面上现有的 Godot 4.7.2，无需联网或安装依赖。
- 也可以在 Godot 中打开 `project.godot`，按 **F5** 运行。
- 游戏启动后选择地图、选择角色颜色，再点击「开始冒险」。

如果移动了 Godot 引擎的位置，可修改启动器中的 `GAME_ENGINE` 路径，或直接从编辑器启动。此目录是完整游戏工程，启动器依赖本机的 Godot 引擎。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 移动；空中可以调整落点 |
| 空格 | 跳跃；羽毛生效时按住空格滑翔 |
| Shift | 滚动冲刺，持续 0.85 秒、冷却 3.2 秒 |
| E | 使用随身道具，也可以点击右下角 E 按钮 |
| R | 回到最近复活点 |
| Esc | 暂停 / 继续；关闭大厅弹窗 |
| F11 | 全屏 / 窗口 |

穿过金色终点环即可完成挑战；星星是额外收集目标。绿色旗帜标记复活点，掉落后自动复活。复活会保留已经收集的星星和道具。

## 六张地图

| 地图 | 特点 |
| --- | --- |
| 糖果巡游 | 旋转糖果棒、弹力球、开合门，适合熟悉操作 |
| 冰淇淋雪原 | 低摩擦冰面、横向浮冰，需要提前减速 |
| 熔岩蹦蹦谷 | 间歇火柱、周期消失的平台与旋转机关 |
| 云端游乐场 | 高低云台、弹床、侧向风与移动岛屿 |
| 蘑菇森友会 | 摆锤、逆向传送带、蘑菇与弹床 |
| 星际失重站 | 低重力长跳、移动平台和旋转障碍 |

每张地图有 7 至 8 段平台、15 至 18 颗星星、2 至 3 个复活点和多个道具盒。各地图的路线、平台高度、机关和物理条件不同。

## 六种道具

一次可以携带一个道具；使用后可继续拾取，不同效果可以叠加。

| 道具 | 效果 |
| --- | --- |
| 汽水加速 | 6 秒内跑步速度提升 65% |
| 泡泡护盾 | 8 秒免疫机关击退，不能抵挡坠落 |
| 弹簧鞋 | 8 秒内起跳速度提升 40% |
| 星星磁铁 | 8 秒吸收周围 7 米内的星星 |
| 轻盈羽毛 | 6 秒内可按住空格减缓下落 |
| 回溯甜甜圈 | 立即回到最近复活点，不增加复活次数 |

五种角色配色，皇冠、兔耳、探险帽三类装饰；背景音乐、跳跃、拾取与通关音效均由程序合成，可以在大厅关闭声音。

## 纪录与工程

最佳用时、角色选择和声音开关保存在 Godot 的 `user://gogo_records.cfg`。Windows 上通常位于 `%APPDATA%\Godot\app_userdata\滚滚奇遇 · GOGO PARTY\`。无需注册或联网。

- `scripts/main.gd`：大厅、游戏状态、追踪镜头、HUD、结算与存档。
- `scripts/course_data.gd`：地图参数、道具定义与角色配色。
- `scripts/course.gd`：生成地形、机关、检查点与拾取物。
- `scripts/runner.gd`：角色物理、移动、跳跃、冲刺与道具效果。
- `scripts/toy_factory.gd`：程序生成的 3D 角色和场景模型。
- `scripts/sound_bank.gd`：程序合成的音乐与音效。
- `tests/`：物理与交互自动检查。
- `artifacts/`：实际渲染截图与测试结果。

项目使用 Godot 的 Compatibility 渲染器与 4× MSAA。中文字体优先使用 Windows 自带的微软雅黑；模型、界面图案和音频无需外部素材下载。

## 验证

在项目目录运行以下命令，将 `godot` 替换为本机的 Godot 控制台程序路径：

```text
godot --headless --path . --fixed-fps 60 --script tests/smoke_test.gd
godot --headless --path . --fixed-fps 60 --script tests/interaction_test.gd
godot --path . -- --capture=artifacts
```

物理测试覆盖六张地图所有平台间隙的普通跳跃、拾取、检查点、坠落复活、全部道具效果以及暂停结算。交互测试向 Godot 场景发送鼠标和物理键盘事件，验证按钮、倒计时、操作、机关与各地图终点触发。自动测试不写入玩家纪录。

已通过 150 项物理及流程检查、81 项输入和机关检查。大厅、道具图鉴、六张地图及结算页面均已在本机实际渲染并截图复核。
